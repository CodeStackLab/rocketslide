# RocketSlide - Mobile Vertical Landing Page WordPress Plugin

A high-speed, isolated vertical landing page plugin for mobile traffic and ads campaign cloaking.

## Features
- **0ms Theme Bypass**: High-performance isolated mobile landing page.
- **Traffic Cloaking Engine**: Advanced crawler/bot filter and redirectional logic.
- **Automated WebP Processing**: Auto-resizes and optimizes 9:16 mobile imagery.
- **Dark Mode Admin Interface**: Modern settings dashboard for managing affiliate links and pixel tracking.

## Installation via WP Pusher
1. Install and activate **WP Pusher** on your WordPress site.
2. In WP Pusher, select **Install Plugin**.
3. Plugin repository: `CodeStackLab/rocketslide`
4. Repository branch: `main` (or leave blank / `master`)
5. Enable **Push-to-Deploy** for automatic GitHub updates.
